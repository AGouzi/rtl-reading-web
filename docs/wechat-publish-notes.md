## 排版建议

- 段落尽量控制在 2–3 行，公众号编辑器里不要沿用 Markdown 的引用块。
- 代码块用编辑器自带的代码样式；安装命令和调用示例保持等宽。
- 页签名称、`valid/ready`、`resp_valid` 等标识符保留原文，不要改成中文。
- 项目地址出现两次即可：第一次在“安装与调用”，第二次在结尾。
- 结尾保留“不能替代仿真、CDC、时序签核”的限制说明，避免读者误解能力边界。
